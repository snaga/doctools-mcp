# 製品概要

## 製品の目的
Gemini-CLI 等のAIクライアントとローカルドキュメント環境を標準化されたプロトコル (MCP) で接続するための、Python製 MCPサーバー。

## コアコンセプト
- **"Document Gateway for AI"**: ローカルのOffice文書やテキストデータを、AIが理解しやすい形式で提供するゲートウェイ。
- **Context-Aware**: 大容量データを直接渡さず、ファイルハンドルや検索インデックスを通じて効率的にアクセスさせる。

## ターゲットユーザー
- Gemini-CLI を使用して、大量のドキュメント（仕様書、データシート、マニュアル等）を参照しながら開発や分析を行いたいエンジニア。
- ローカルファイルを安全かつ効率的にAIに読み込ませたいユーザー。

## 主要機能
- **DocTools (ドキュメント操作)**:
  - **PDF**: ページ分割、テキスト抽出、ページカウント、特定ページの画像化（PNG/JPG）。
  - **PowerPoint**: テキスト抽出、スライドカウント、スライド抽出（切り出し）、特定スライドの画像化（PNG/JPG）、複数ファイルのマージ。
  - **Excel**: シート一覧取得、シートCSV抽出、シート抽出（別ファイル保存）、特定シートの画像化（PNG/JPG）。
  - **CSV**: 範囲指定抽出、データ検索、メタデータ取得（文字コード判別含む）。
  - **HTML**: テキスト抽出（Markdown）。
  - **IMAGE**: PNG メタデータ取得（サイズ特定）、指定領域の切り抜き（Crop）、クリップボード画像からのPNG保存。
  - **TEXT**: 文字コード変換、先頭/末尾行抽出、Grep検索、メタデータ取得。
  - **Utility**: ZIP圧縮・解凍。
- **PageIndex (推論ベースRAG支援)**:
  - **Structure Extraction**: LLM がドキュメントの階層構造を把握するためのメタデータ（PDFのTOC、PPTXのスライド構成、Excelのシート情報）を抽出。
  - **Validation**: AI が生成した PageIndex 互換 JSON の構造が正しいか、JSON Schema を用いて決定論的に検証。
  - **Node Retrieval**: AI がインデックス探索により特定した特定のノード（ページ、スライド、シート）のコンテンツをピンポイントで取得。
- **Search (全文検索)**:
  - **Indexing**: ローカル文書（PDF, PPTX, XLSX, DOCX）のインデックス構築。
  - **Full-text Search**: N-gram による日本語対応全文検索。
  - **Faceting**: ディレクトリによる検索範囲の絞り込み。

## ビジネス目標
AIエージェントがローカルの知識ベースを最大限に活用できる環境を提供し、ドキュメントに基づいた回答精度と作業効率を向上させる。
また、GCP Gemini API だけでなく Vertex AI などのエンタープライズ環境にも対応し、セキュリティやガバナンスの要件に応じた柔軟なデプロイを可能にする。
